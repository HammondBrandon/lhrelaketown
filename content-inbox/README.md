# Content inbox

Drop Lindsey's raw files here. This folder is gitignored, except for this README. Use one folder per item so it's clear what each file is for:

```
content-inbox/
  hero-message/          video file + captions (.srt/.vtt) + poster still
  gallery/
    film-1/              video + 1–2 stills + one line: property, town, permission confirmed (Y/date)
    photo-1/
    campaign-1/
    bts-1/
  walkthrough/           the chosen campaign: one subfolder per step (pricing, prep, shoot, launch, leads, showings, offers, closing)
  case-studies/
    case-1/              lead photo + notes.txt: property, location, strategy, marketing steps, timeline, result
  testimonials.txt       exact quote, name as approved, context, permission date
  stats.txt              closed transactions (period), avg DOM + baseline, sale-to-list, lake/land/new-construction sales
  capacity.txt           backup agent, transaction coordinator, lead-response standard, on-site days
  mls/                   MLS export: active + sold lake lots, Randolph and Clay counties
  lindsey/               headshot, bio, personal note to Troy, license numbers
  lake-footage/          original Lake Wedowee footage (water or public access only)
```

Every client asset needs that client's permission before it's used.
